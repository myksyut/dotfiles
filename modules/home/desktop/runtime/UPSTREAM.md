# Upstream

This desktop setup is adapted from [duma799/yabai-config](https://github.com/duma799/yabai-config), revision `61f80adfed993c10dd111f1c81bf624c04c99c53`.

The upstream checkout at this revision contains no LICENSE or COPYING file. No new license for that upstream work is asserted here.

Local changes include SIP-compatible window operations, Ghostty/Zen/Zed launchers, stable resize/swap behavior, SketchyBar synchronization, contrast-aware palette rendering, the Sky Copy palette, and Home Manager packaging. The Nix integration uses Homebrew's macOS binaries and a Nix-managed Python environment.
