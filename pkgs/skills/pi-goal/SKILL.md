# pi-goal

Pi の `pi-goal` runtime は Claude Code には無い。同じ動きを手順で再現する。

## 手順

1. 目的を一文で固定し、完了条件を観測可能な結果にする。
2. 完了条件を満たすまで調査・実装・検証を続ける。
3. 目的外のリファクタ、新規機能、範囲拡大をしない。
4. 完了条件を満たしたら止まり、結果だけを報告する。
5. 計画が必要な変更は、先に grill → `.context/todo.md` → Plannotator を通す。
